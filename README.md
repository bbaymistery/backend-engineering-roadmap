# 🚀 Backend Engineering Roadmap & NestJS Projects

Bu repozitoriya **NestJS** və **Nx Monorepo** texnologiyaları üzərində qurulmuş backend təlim və proyekti özündə əks etdirir.

---

## 📌 Qovluq Strukturu Və Layihələr

* **`1_poster_parlor/new-poster-parlor-api`** ➡️ **Əsas Aktiv Layihə:** NestJS və Nx Monorepo ilə hazırlanmış Poster Parlor Backend API tətbiqi.
* **`1_poster_parlor/poster-parlor`** ➡️ **Orijinal Referans Layihə:** Başlanğıc referans koda malik ilk versiya.

---

## 🛠️ İstifadə Olunan Texnologiyalar

* **Backend Framework:** NestJS (Node.js)
* **Architecture:** Nx Monorepo (Apps & Libs)
* **Database & ORM:** PostgreSQL & TypeORM
* **Containerization:** Docker & Docker Compose
* **Code Quality & Tooling:** ESLint, Prettier, TypeScript

---

## ⚡ Tez Başlama (Quick Start)

1. Layihə qovluğuna keçin:
```bash
cd 1_poster_parlor/new-poster-parlor-api
```

2. Tətbiqi Development rejimində işə salın:
```bash
npm run dev
```
