# 🗄️ Database Qovluğu (`src/database`)

### Nə üçün istifadə olunur?
Verilənlər bazası (Database: PostgreSQL, MongoDB, TypeORM, Prisma) bağlantılarını və servislərini idarə etmək üçün istifadə olunur.

### Nümunə Fayllar:
- **`database.service.ts`**: Verilənlər bazasına müraciət edən servis (Öyrənmə məqsədilə burada daxili massivdən - In-memory Mock Data-dan istifadə olunub).
- **`database.module.ts`**: Baza servisini digər modullara təqdim edən modul.
