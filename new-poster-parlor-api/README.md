# 🚀 Poster Parlor API (NestJS + Nx Monorepo)

Bura **NestJS** və **Nx Monorepo** arxitekturası ilə yaradılmış aktiv backend tətbiqidir!

---

## 📌 Qısa Məlumat

* **Əsas Texnologiya:** NestJS
* **Arxitektura:** Nx Monorepo (`apps/` və `libs/`)
* **Orijinal Referans Layihə:** `poster-parlor`

---

## ⚡ İşə Salmaq (Run Command)

```bash
npm run dev
```

---

## 📁 Qovluq Strukturu

* `apps/api/` — NestJS Backend API (src/main.ts)
* `apps/api-e2e/` — Avtomatik E2E Testlər
* `libs/` — Ortaq Kitabxanalar (Auth, Database, Order, Inventory, Utils, Config, Logger, Admin, Shared...)
* `readmes/` — Əmrlər tarixçəsi və skript təlimatları
