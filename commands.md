# Short acixlamalar

## CLI nədir?

CLI (Command Line Interface) — terminalda yazdığın əmrlərlə işləyən idarəetmə alətidir.

Faylları qovluq açıb əllə yaratmaq yerinə, terminala bir sətir əmr yazırsan və sənin üçün lazım olan bütün faylları, şablonları və konfiqurasiyaları avtomatik hazırlayır.
