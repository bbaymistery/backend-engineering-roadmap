# 🤝 Shared Qovluğu (`src/shared`)

### Nə üçün istifadə olunur?
Layihənin birdən çox modulu tərəfindən **ümumi/paylaşılan** (shared) servislər və funksionallıqlar burada yerləşir.

### Nümunə Fayllar:
- **`services/logger.service.ts`**: Bütün modulların istifadə edə biləcəyi ümumi Loqlama servisi.
- Ümumi interfeyslər (Interfaces), Enumlər və ya Sabitlər (Constants).
